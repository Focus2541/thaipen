# ถ่ายเป็น — กล้องสอนถ่ายรูป

PWA ฟรี ภาษาไทย สำหรับมือใหม่ เปิดกล้องแล้วแอปบอกวิธีจัดภาพ เลือกโทน และแต่งรูปให้อัตโนมัติ ประมวลผลในเครื่องทั้งหมด ใช้ออฟไลน์ได้หลังเปิดครั้งแรก

เปิดใช้: https://focus2541.github.io/thaipen/

- โค้ชสด: เส้น 1/3 + จุดเป้าหมาย, เตือนกล้องเอียง/ตัดหัว-ข้อต่อ/ชิดขอบ/ย้อนแสง/มืด/สั่น (MediaPipe Face + Pose, เซนเซอร์มือถือ)
- คะแนน 0–100 เป็นวงแหวนสี + ถ่ายอัตโนมัติเมื่อคะแนนถึงและนิ่ง 1 วินาที
- โหมดฉาก: วิว / คน 1 คน / คนคู่ / อาหาร / ตึกเมือง (หรือให้แอปเดา)
- โทนอัตโนมัติ 5 แบบจาก FilmCam + Original พร้อมเหตุผล
- นำเข้ารูป / ถ่ายด้วยแอปกล้องมือถือ → แก้เอียง ครอป 1/3 ปรับแสง ใส่โทน · เทียบก่อน/หลัง · เก็บต้นฉบับเสมอ
- สรุปรูป: ทำดี 1 ข้อ + ควรปรับ 1 ข้อ
- อัลบั้ม (IndexedDB), ปัดดูรูป, เลือกหลายรูปลบ, สำรอง/กู้คืน .zip
- ถาม AI (Gemini, ใช้ API key ของตัวเอง เก็บในเครื่อง)

ไฟล์: `engine.js` (โทน/LUT/WebGL จาก FilmCam) · `coach.js` (วิเคราะห์ภาพ กฎจัดภาพ แต่งอัตโนมัติ) · `app.js` (หน้าจอ) · `sw.js` (ออฟไลน์ — เปลี่ยนเลข CACHE ทุกครั้งที่แก้ไฟล์)
